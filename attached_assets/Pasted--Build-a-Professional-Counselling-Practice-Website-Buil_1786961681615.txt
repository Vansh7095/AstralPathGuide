# Build a Professional Counselling Practice Website

Build a production-ready, modern, responsive website for a professional counselling practice. The counsellor is the owner's mother, and she will personally provide the counselling sessions.

This is a real business website, so it must look trustworthy, calm, professional, premium, and human — NOT like a generic AI-generated template.

## 1. Main Goal

Create a complete counselling practice website where visitors can:

* Understand who the counsellor is
* Learn about the counselling services offered
* Understand the counselling process
* Read FAQs
* Contact the counsellor
* Request/book an appointment
* Optionally create an account if authentication is enabled
* Find the practice through Google
* Contact the counsellor through WhatsApp/phone/email
* Use the website comfortably on mobile, tablet, and desktop

The website should establish trust without making exaggerated medical or psychological claims.

Do NOT claim guaranteed results, cures, diagnoses, or outcomes.

---

# 2. Tech Stack

Use a modern production-ready stack.

Preferred:

* Next.js with App Router
* TypeScript
* Tailwind CSS
* shadcn/ui where useful
* Lucide icons
* PostgreSQL for persistent data
* Drizzle ORM
* Zod for validation
* React Hook Form for forms
* Server-side API/actions where appropriate

If the Replit environment has an existing preferred stack, adapt to it rather than unnecessarily fighting the environment.

Use clean, maintainable TypeScript.

Do not create unnecessary complexity.

---

# 3. Design Direction

The website should feel:

* Calm
* Trustworthy
* Warm
* Professional
* Private
* Modern
* Human
* Premium but not flashy

Avoid:

* Neon colors
* Excessive gradients
* Gaming-style UI
* Excessive animations
* Huge unnecessary text
* Generic stock-photo-heavy design
* Overly clinical hospital aesthetics

Use a soft, elegant visual system.

Suggested palette:

* Warm white / off-white backgrounds
* Soft sage/green or muted blue-green accents
* Dark charcoal text
* Very subtle secondary colors

Typography should be highly readable.

Use generous whitespace.

Cards should have subtle borders/shadows rather than excessive effects.

---

# 4. Responsive Design

The website must be fully responsive.

Prioritize mobile because many potential clients will probably access the website from their phones.

Test:

* 360px
* 390px
* 414px
* 768px
* 1024px
* 1280px+

Navigation must work properly on mobile.

Buttons must be large enough to tap comfortably.

WhatsApp/contact/appointment CTAs should remain easy to find.

# 8. Appointment Booking

Build an appointment request/booking system.

Visitors should be able to:

* Select counselling service
* Select preferred date
* Select available time
* Enter name
* Enter email
* Enter phone number
* Optionally enter a short reason/message
* Submit appointment request

Do NOT request unnecessary sensitive information.

The form should clearly state that users should not submit emergency information or highly sensitive personal/medical details through a normal website form.

After submission:

* Show confirmation
* Save appointment in database
* Notify admin/counsellor
* Prevent obvious duplicate submissions
* Validate all fields
* Sanitize input

The counsellor/admin should be able to:

* View appointments
* Approve/reject/reschedule
* Change appointment status
* View client contact information
* Add notes only if the system is explicitly designed to securely support them

Do not expose admin information publicly.

---

# 9. Booking Availability

Create an availability system.

Admin should be able to configure:

* Working days
* Working hours
* Breaks
* Holidays/unavailable dates
* Session duration
* Buffer time between appointments

The public booking page should only display available slots.

Prevent double booking.

Store all dates/times consistently and handle timezone correctly.

Default timezone should be configurable, with India (Asia/Kolkata) as the initial default if the practice is based in India.

* Terms & Conditions page

* It is not an emergency service

* How appointment data is handled

# 18. Sensitive Information

Minimize collection of sensitive information.

Do NOT ask users to provide:

* Detailed medical history
* Diagnoses
* Medication information
* Extremely personal life history

during a normal contact/booking form unless specifically required and appropriately secured.

The booking form should use a simple optional field such as:

"Anything you'd like us to know before contacting you?"

with a warning not to submit sensitive information.

* Client accounts
* Google login
* OTP

* Video calling
* Chat

first structure the application so these can be added later.

The initial version should focus on:

**Professional website + counsellor information + services + contact + WhatsApp + appointment booking + secure admin management + SEO + privacy + deployment readiness.**

Build this as a polished real-world product rather than a demo.

Start by creating the project structure, database schema, configuration system, and core UI. Then implement the public website, booking system, authentication/admin functionality, SEO, security, and deployment configuration.
